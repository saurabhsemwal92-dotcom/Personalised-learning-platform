# Personalised-learning-platform

A beginner-friendly **frontend web application** designed to provide an interactive and personalized learning experience. The platform allows users to register and log in, explore learning subjects such as **Math and Science**, take quizzes, and track their learning progress through a simple dashboard.

The project is built using **HTML, CSS, and JavaScript**, with JavaScript DOM manipulation used to create interactive features and manage user interactions.

### Key Features

* User Registration and Login
* Subject-based Learning Sections
* Interactive Random Quizzes
* Score Tracking
* Progress Dashboard
* Responsive and Modern UI
* Frontend-only implementation using JavaScript DOM manipulation

### Purpose

This project was created to practice **frontend development, JavaScript, DOM manipulation, UI design, and interactive web application development**.
